## 一、注册美区 Apple ID

1. 打开苹果官网：[https://appleid.apple.com/account](https://appleid.apple.com/account)

   ![](https://s2.loli.net/2023/03/31/Rzm5Opv4lTPgDqQ.jpg)

2. 填写信息：

   - **地区**：选择 **美国**
   - **出生日期**：务必填写年龄 **大于18岁**
   - **邮箱**：必须是 **从未注册过 Apple ID** 的邮箱
   - **密码**：不要包含生日、邮箱、姓名等信息，否则可能卡在验证步骤
   - **手机号码**：可以填写已注册过 Apple ID 的手机号，只要 **能接收验证码即可**

   ![](https://s2.loli.net/2023/03/31/SAmMfCkWXyotrRp.jpg)

3. 验证邮箱和手机，填写验证码

   ![](https://s2.loli.net/2023/04/03/ltXMPNqCyDG4ukn.jpg)

4. 账号注册完成

## 二、登录 App Store 并设置付款方式

1. 打开 **App Store**  
2. 点击右上角头像，滑到底部，**退出当前账号**
3. 登录刚刚注册的美区 Apple ID

   ![](https://s2.loli.net/2023/04/03/458yQmgatKiUkLA.jpg)

4. 设置付款方式：

   - 地址可通过 [地址生成器](https://id123.cc) 生成
   - 包括街道、城市、邮编等信息都可以生成
   - 最后付款方式选择：**无**

   - **建议选择以下五个免税州，避免后续消费产生税费**：
     1. 俄勒冈州（Oregon）
     2. 阿拉斯加州（Alaska）
     3. 特拉华州（Delaware）
     4. 蒙大拿州（Montana）
     5. 新罕布什尔州（New Hampshire）

   ![](https://s2.loli.net/2023/04/03/Uu5JOnaQ8Hs9wW2.jpg)
